Privacy Policy

LabWorx Mobile Applications • Last updated: September 18, 2026

This Privacy Policy governs the mobile software applications developed and published by LabWorx ("we", "us", or "our"), including LabWorx Managed Config Demo, LabWorx LostMode, and any future utility applications distributed via Google Play and Managed Google Play.

1. General Principle: Zero Data Collection

All LabWorx applications operate with a strict Zero Remote Data Collection architecture:

  • We do not collect, process, track, transmit, or monetize any personal identifiable information (PII) or device data.
  • Our applications run completely offline without remote telemetry, crash logging tools, or third-party analytics trackers.
  • Our applications do not include advertising SDKs or third-party tracking frameworks.

2. Application-Specific Data Handling

Application Disclosure

LabWorx LostMode

An enterprise kiosk utility designed to display custom emergency or recovery information when a managed device is marked lost.

  • Permissions: Requests zero runtime or system permissions in its manifest (including no INTERNET permission). It runs entirely isolated and offline.
  • Local Volatile Memory: Configuration strings (canvas background colors, font sizing, and notification text) delivered via Android's native RestrictionsManager are processed solely in temporary RAM to render the screen. Nothing is stored in persistent local databases or sent outside the device.
  • No Interactivity: The app does not collect user inputs, form submissions, or touch analytics.
Application Disclosure

LabWorx Managed Config Demo

A technical demonstration utility for evaluating Android Managed Configurations via Enterprise Mobility Management (EMM/MDM) solutions.

  • Permissions: Operates entirely offline with zero network permissions requested in its manifest.
  • Sandbox Data Persistence: Field values (User Name, Email Address, Serial Number) and demo sync timestamps are stored strictly on the device using Jetpack DataStore within the private app sandbox. This data never leaves the handset and is permanently removed upon app uninstallation.
  • Managed Configuration Sync: Restrictions received via ACTION_APPLICATION_RESTRICTIONS_CHANGED are applied locally via the standard Android framework.
Framework Default

Future LabWorx Utilities
