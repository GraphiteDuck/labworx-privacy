Privacy Policy

LabWorx ManagedConfig Demo • Last updated: September 8, 2026

This Privacy Policy applies to the mobile application LabWorx ManagedConfig Demo (the "Application"), developed and published by LabWorx ("we", "us", or "our"). The Application is distributed as a private enterprise utility via Managed Google Play for authorized enterprise environments, technical evaluation, and demonstration of Android Managed Configurations.

1. Information Collection, Storage, and Configuration

  • Zero Remote Data Collection: The Application does not collect, track, transmit, or sell any personal information or sensitive device data to external servers, cloud databases, or third-party service providers.
  • Demonstration Input Fields: The Application features local input fields labeled User (username), Email (email address), and Serial (serial number). These fields function exclusively for demonstration and testing of enterprise configuration behavior:
    • Local Preferences Active: When edited directly on the device, any entered values are saved strictly within local, sandboxed device storage (SharedPreferences). They are never uploaded or transmitted off the handset.
    • Enterprise Managed Configurations: When configured remotely by an IT administrator via an Enterprise Mobility Management (EMM) or Unified Endpoint Management (UEM) system, the configuration values are applied locally via standard Android enterprise APIs (RestrictionsManager). They remain confined to the app sandbox and are never sent to external servers by LabWorx.
  • No Telemetry, Analytics, or Advertising: The Application does not contain advertising libraries, analytics trackers, or user behavioral profiling tools.

2. Device Permissions and Access

The Application requests only standard runtime/install permissions strictly required to demonstrate enterprise configuration sync functions. The Application does not request or access sensitive device components such as contacts, photos, microphone, camera, or precise geolocation.

3. Third-Party Sharing and Disclosures

  • We do not sell, rent, or lease any data entered into or processed by the Application.
  • We do not share data with third-party advertising or marketing services.
  • Any network requests initiated by enterprise features connect strictly to designated internal endpoints defined by your organization's IT policies, entirely bypassing LabWorx.

4. Data Retention and Sandbox Security

Because LabWorx does not operate backend servers that collect data from this Application, we do not store, retain, or manage user records. All local input values and synchronized managed configuration strings reside solely in isolated application storage on the target device. Clearing the app storage or uninstalling the Application permanently removes all saved demo values.

5. Children’s Privacy

The Application is designed exclusively for enterprise IT administrators and business testing purposes. It is not intended for or marketed to individuals under the age of 13, and we do not knowingly collect information from children.

6. Updates to This Policy

We may periodically revise this Privacy Policy to reflect app updates or regulatory changes. Any modifications will be posted here with an updated "Last updated" date.
