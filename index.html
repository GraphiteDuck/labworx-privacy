Privacy Policy

LabWorx Mobile Applications • Effective Date: September 20, 2026

This Privacy Policy governs the mobile software applications developed and published by LabWorx ("we", "us", or "our"), including LabWorx Virtual Buttons, LabWorx Managed Config Demo, LabWorx LostMode, and any utility applications distributed via Google Play and Managed Google Play.

1. General Principle: Zero Remote Data Collection

All LabWorx applications operate with a strict Zero Remote Data Collection architecture:

  • No Data Collection or Transmission: We do not collect, process, record, profile, harvest, or monetize any personal information, hardware serial numbers, advertising IDs, or usage analytics.
  • No Internet Communication: Our applications do not declare or request the android.permission.INTERNET permission in their manifests and function completely offline.
  • No Third-Party SDKs: Our codebases contain zero third-party software development kits (SDKs), advertising networks, telemetry monitors, or remote crash reporters (e.g., no Firebase, AdMob, or Sentry).

2. User Accounts & Data Deletion

In compliance with Google Play Developer Policies:

  • No User Accounts: LabWorx applications do not create, host, or link user accounts, credentials, or profiles.
  • Account Deletion Exemption: Because no user profiles or personal records are maintained on any remote servers, no account deletion mechanisms or web deletion request forms are required.
  • Local Cache Removal: Any operational preferences stored locally on the device (within private sandbox storage like Jetpack DataStore) can be removed at any time via Android Settings > Apps > [App Name] > Storage > Clear Data or by uninstalling the application.

3. Application-Specific Disclosures & Permissions

Application Disclosure

LabWorx Virtual Buttons

An assistive utility providing on-screen software replacements for hardware buttons (such as lock screen toggles and media volume controls), designed for users with impaired motor functions or devices with malfunctioning physical buttons.

1. AccessibilityService API Disclosure (Mandatory Google Play Notice)

  • Specific Scope & Purpose: The application uses the Android Accessibility Service API (VirtualAccessibilityService) strictly to trigger the system-level lock screen action (GLOBAL_ACTION_LOCK_SCREEN) upon direct user interaction.
  • No Content Inspection or Logging: The service is explicitly declared with canRetrieveWindowContent="false". It does not read, intercept, monitor, inspect, log, or transmit on-screen text, gestures, keystrokes, personal communications, or user interactions.
  • No Audio or Surveillance: The Accessibility Service is never used for audio recording, call recording, background surveillance, remote access, or bypassing system security controls.
  • Prominent In-App Consent: The application displays a prominent disclosure explaining these exact capabilities and requests voluntary user consent before guiding the user to Android Settings to activate the service. Users can disable this permission at any time via system settings.

2. Additional Permissions & Data Handling

  • Quick Settings Tiles (BIND_QUICK_SETTINGS_TILE): Used exclusively to display optional "Screen Lock" and "Media Volume" tiles within the device's Quick Settings notification shade.
  • Zero Telemetry & Offline Architecture: Contains no analytics SDKs, advertising frameworks, crash-logging tools, or remote network access (no INTERNET permission requested).
  • No Accounts or Remote Storage: Does not create or manage user accounts, and stores zero personal data locally or in the cloud.
Application Disclosure

LabWorx LostMode

An enterprise kiosk utility designed to display administrative recovery details and contact notices when a managed handset is marked lost.

  • Permissions: Declares zero runtime or system permissions in its manifest (including no INTERNET permission).
  • Volatile Memory (RAM): Managed enterprise configuration strings received via Android's native RestrictionsManager are processed solely in temporary volatile memory to render the UI. No records are written to persistent databases or transmitted off-device.
  • No Interactivity: Collects no user inputs, forms, keystrokes, or touch analytics.
Application Disclosure

LabWorx Managed Config Demo

A technical demonstration utility for evaluating Android Managed Configurations via Enterprise Mobility Management (EMM/MDM) solutions.

  • Permissions: Operates entirely offline with zero network permissions.
  • Local Sandbox Persistence: Field values (User Name, Email Address, Serial Number) and sync timestamps are stored strictly on the device using Jetpack DataStore within the private app sandbox. This data never leaves the handset and is purged upon app uninstallation.
  • Managed Configuration Sync: Restrictions received via ACTION_APPLICATION_RESTRICTIONS_CHANGED are applied locally via the standard Android framework.
Framework Default

Future LabWorx Utilities
